# 実機受入チェック

ここに並ぶ実サービスの項目は、認証設定後に実施する未完了の受入チェックです。

## AlexaとTodoist

- [ ] 日本語対話モデルのBuild Modelが成功する。
- [ ] 呼び出し名「やること相棒」でEcho実機から起動できる。
- [ ] 実際の署名証明書をWorkersで検証できる（キャッシュあり／なし）。
- [ ] 不正署名・別userId・別Skill IDが拒否される。
- [ ] 「牛乳を追加」→「いいえ」でTodoistが変わらない。
- [ ] 「牛乳を追加」→「はい」でInboxに1件だけ追加される。
- [ ] 今日の一覧、続き、0件、長いタスク名を読み上げられる。
- [ ] 一覧表示後にTodoistで別タスクを追加しても「二番」が変わらない。
- [ ] 完了後も別番号が詰まらない。
- [ ] セッション終了後の番号操作は再一覧からやり直す。
- [ ] 繰り返し完了は今回分のみ。延期は拒否する。
- [ ] 子タスクを持つ親の完了を拒否する。
- [ ] 期限時刻あり／なしで、翌日本時間へ正しく延期する。
- [ ] APIの応答欠落後は結果不明と案内し、同じUUIDで再確認できる。

## Echo Show 5

- [ ] APL 1.4文書を描画でき、長い文字がボタンを隠さない。
- [ ] 完了／明日へ→音声確認→はいが動く。
- [ ] 一覧更新後の古いイベントで別タスクを操作しない。
- [ ] APLを無効化すると音声だけで4操作が使える。

## 無料枠・運用

- [ ] CloudflareはWorkers Freeのまま。
- [ ] キャッシュなしを含むCPU時間に10msを超える継続的負荷がなく、Error 1102が発生しない。
- [ ] Alexaに時間内に応答できる。
- [ ] ログにタスク名・本文・トークンが出ない。
- [ ] トークン更新後も接続できる。

CPU時間はCloudflareのWorker Metricsで確認します。ローカルの壁時計やテスト全体の時間をCPU時間と同一視しません。
費用条件を満たせない場合は、先に構成・プランを判断し、署名検証を省略しないでください。
